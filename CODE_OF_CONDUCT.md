# Code of Conduct

This project aims to be a welcoming, practical, and technically rigorous community.

## Expected behavior

- Be respectful, patient, and constructive.
- Discuss ideas and evidence rather than attacking people.
- Welcome questions and different levels of experience.
- Give feedback that is specific, actionable, and proportional.
- Respect privacy, attribution, and responsible security disclosure.
- Accept correction and focus on improving the shared work.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized conduct, deliberate intimidation, doxxing, sustained disruption, or publishing another person's private information without permission are not acceptable.

## Enforcement

Report conduct concerns privately to the repository maintainers through a contact method on their GitHub profiles. Maintainers may edit or remove contributions, limit participation, or take other proportionate action to protect the community. Reports should be handled discreetly, fairly, and without retaliation.

By participating, contributors agree to follow these expectations in project spaces and when representing the project publicly.
